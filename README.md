# Portafolio de Frank Flores

Sitio estático (HTML, CSS y JavaScript, sin dependencias) publicado con GitHub Pages en
https://frankfloresg-primeuni.github.io

- `index.html`: toda la página. Los proyectos, la trayectoria y las habilidades están en arreglos al inicio del `<script>` (`projects`, `path`, `skills`).
- `assets/`: fotos y certificado.
- `Frank_Flores_CV.pdf`: CV que se abre desde el botón "Ver CV".

Para agregar el repositorio de un proyecto, cambia `repo:null` por la URL del repo en el arreglo `projects`.
